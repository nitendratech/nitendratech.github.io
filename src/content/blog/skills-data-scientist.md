By the name “Data Scientist” itself, one needs to understand and feel the [data](https://www.nitendratech.com/datascience/data-explained/). For this, one needs a certain set of technical skills that will provide you with the technical expertise and intuition for analyzing data. Once you learn these skills, you can use your intuition and knowledge to discover trends in data and find patterns in it.

Below are some skills/concepts that you need to start your career as a Data Scientist.

- **Basic Statistics**

You need to have good statistical knowledge to understand data. Learn about Mean, Median, Experimental Designs, and other concepts. This is a good source to start on this. [Introduction to Basic Concepts](http://bobhall.tamu.edu/FiniteMath/Module8/Introduction.html)

- **Advanced Statistical Modelling techniques**

Learn about curve fitting, regression (linear/multivariate/logistic/lasso/ridge), and prediction techniques using these statistical models. Example Source: Advanced Statistics, [5 Advanced Stats Techniques & When to Use Them](https://measuringu.com/advanced-stats/)

- **R** Programming

R is an open-source and one of the most popular languages in terms of statistical modeling. It will help you to simulate your model and apply statistical techniques. It also helps you to visualize the predicted results from your model

- **Pytho**n

If you are good at programming you can learn Python too as you can use it independently or in combination with R. Python provides some good sets of Machine learning libraries like sci-kit-learn.

- **Data Mining and Related Concepts**

It helps you to discover patterns and trends in large data sets. It is the intersection of artificial intelligence, machine learning, statistics, and database systems. Source: [Data mining – Wikipedia](https://en.wikipedia.org/wiki/Data_mining)

- **Visualization Tools:**

Along with the skill to develop a prediction model and identify trends, a data scientist should be able to visualize their final data. To do that you can learn some tools such as Tableau Public,D3.js – Data-Driven Documents), and [RAWGraphs](http://rawgraphs.io/) depending upon your level of expertise.
